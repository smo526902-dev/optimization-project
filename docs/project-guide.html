How it was built

Each stage adds one layer on top of the last

We built the project bottom-up. A stage starts only when the layer under it passes its tests. Step through to see which files each stage added and what it showed.

The algorithm

The MA is the GA loop with one step changed

One generation runs six steps. Only Evaluate spends budget in the GA. The MA keeps all six and replaces only Learn.

The results

Local search fixes valleys, not far-away basins

Three landscape shapes explain most of the 30-run results. Numbers are median final errors at 10-D over 30 runs; errors below 10⁻⁸ count as 0.

Over all 30 problems, the MA beats the GA on 17, ties on 13 and never loses (Wilcoxon rank-sum, α = 0.05; 12 / 18 / 0 after Holm correction). The ties are problems both algorithms solve. Against DE the MA wins 10, ties 16 and loses 4. As in the CEC benchmark rules, errors below 10⁻⁸ count as 0, so rounding noise is never a win. Full tables: experiments/results/full/tables/.

Every file

Four folders: library, scripts, tests, outputs

You change code only in the first three. The fourth holds generated files, which the scripts write again on every run.

evoopt/

The library: the algorithms and everything they need. No file here reads or writes disk.

benchmarks.pystage 1
The 12 test functions. Each takes a population X (n rows × d columns) and returns n values in one numpy call. BenchmarkFunction stores the domain, f*, x*, SFU category and formula.sphere … styblinski_tang · BenchmarkFunction · FUNCTIONS · get_function
problem.pystage 1
One task: a function, a dimension and a budget. evaluate() is the only way to compute f. It counts calls, returns +inf past the budget, and records the best point and when it was found.Problem.evaluate · evaluate_one · best_at · random_points · clip
operators.pystage 2
Three selection operators (tournament, roulette, rank), three crossovers (SBX, BLX-α, arithmetic) and three mutations (polynomial, Gaussian, uniform). Lower f is always better.tournament_selection · sbx_crossover · polynomial_mutation · …
ga.pystage 2
GAConfig holds every setting with a default. GeneticAlgorithm.run() loops step() until the budget is spent; learn() is an empty hook.GAConfig · run · step · make_offspring · learn · select · crossover · mutate
results.pystage 2
RunResult: best x and f, error, the trace of improvements, per-generation history, and a one-row summary for tables.RunResult · from_problem · error_at · evals_to_reach · summary · best_so_far
local_search.pystage 3
Two local searches. Hooke–Jeeves tries ± a step on each variable, then jumps in the direction that worked. Hill climbing tries random steps with the 1/5 success rule. Both return their final step size, so a search can resume later.hooke_jeeves · hill_climbing · converged · LOCAL_SEARCHES
ma.pystage 3
MemeticAlgorithm inherits the GA and overrides only learn(): it refines the best individual (20·d evaluations) and each child with probability 5% (5·d). Lamarckian learning writes the improved genes back; Baldwinian keeps only the fitness.MAConfig · MemeticAlgorithm.learn · reset_learning
baselines.pystage 4
Random search, the floor any method must beat, and SciPy's Differential Evolution, an outside reference. Both evaluate through Problem.RandomSearch · ScipyDE
__init__.pyevery stage
Makes evoopt a package, exports the main classes, and holds ALGORITHMS: the names ga, ma, rs and de used on the command line.

experiments/

Limits each worker process to one BLAS thread and sets WORKERS = 16, so parallel runs do not run out of memory on Windows.
pilot_ma.pystage 3
The pilot study that chose the MA's local-search settings. It uses seeds 100–104 only, so the choice cannot leak into the main results.
head_to_head.pystage 3
A quick GA-vs-MA comparison on every function, 10 seeds each, with a Wilcoxon test.
config.pystage 4
What the experiment runs: 30 problems × 4 algorithms × 30 seeds, the 10,000·d budget, the success threshold 10⁻⁴, the 10⁻⁸ error floor, and the 8 ablation studies.
run.pystage 4

analyze.pystage 4
Reads the raw results, counts errors below 10⁻⁸ as 0 (CEC rule), and writes the summary and statistics tables, convergence curves, box plots, the success heatmap, the ablation tables and the population pictures.summarise · statistics_tables · holm · convergence_figures · ablation_outputs

tests/

307 automated checks. Run them all with python -m pytest in about a minute.

test_benchmarks.py193 tests
Every function, every dimension: f(x*) = f*, no random point beats f*, small nudges around x* never beat it, x* is inside the domain.
test_problem.py6 tests
Every call is counted, the budget is a hard limit, and the best point and trace are recorded correctly.
test_operators.py22 tests
Selection favours low f; children stay inside the domain; SBX children are symmetric around their parents; mutation rate controls how many genes change.
test_ga.py39 tests
The GA solves Sphere, spends exactly the budget, repeats with the same seed, never loses its best, and runs with all 27 operator combinations.
test_local_search.py17 tests
Both searches solve Sphere, never return a worse point, stay in bounds, and respect both budgets.
test_ma.py16 tests
The MA with learning off equals the GA; the MA beats the GA on Rosenbrock; Lamarckian and Baldwinian learning behave as defined.
test_baselines.py5 tests
The baselines respect the budget, and the runner merges settings that are really the same.
test_analysis.py4 tests
The 10⁻⁸ error floor: rounding noise is never a win or a loss. Also checks the Holm correction.
